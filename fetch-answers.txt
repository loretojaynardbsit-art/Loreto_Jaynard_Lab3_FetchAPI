1. What are the main differences between XMLHttpRequest and Fetch API?

XMLHttpRequest is an older JavaScript method for making HTTP requests and usually requires more code and event handling. The Fetch API is a newer approach that uses Promises and provides a cleaner and simpler way to make HTTP requests. Both can communicate with servers and handle data such as JSON.


2. Why is the Fetch API considered more modern and readable?

The Fetch API is considered more modern because it uses Promises and has a cleaner syntax compared to XMLHttpRequest. It allows developers to organize asynchronous operations using .then() and .catch(). This makes the code easier to read, understand, and maintain.


3. What is the purpose of the .then() and .catch() methods in Fetch?

The .then() method is used to handle a successful step in the Promise chain, such as receiving a response or converting the response into JSON. The .catch() method is used to handle errors that occur during the request or processing of the Promise.


4. What happens when you send a POST request to the placeholder API?

When a POST request is sent to the JSONPlaceholder API, the API receives the data and simulates creating a new post. It returns a JSON response containing the submitted information and a generated ID. In this activity, the returned post ID is 101.
